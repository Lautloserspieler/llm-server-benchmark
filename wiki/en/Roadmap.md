# Roadmap

The canonical roadmap lives in the repository:

[Open ROADMAP.md](https://github.com/Lautloserspieler/llm-server-benchmark/blob/main/ROADMAP.md)

## Already available

- llama.cpp and vLLM
- NVIDIA and AMD telemetry
- CPU/GPU/hybrid execution
- long context
- TTFT/concurrency
- soak, OOM, multi-tenant, quantization tests
- HTML/PDF/CSV/JSON
- strict comparability validation
- Windows/Linux/macOS launchers

## Larger next steps

- make stress paths more backend-independent
- TGI
- Ollama
- Intel telemetry
- further reproducibility and setup improvements

This Wiki page intentionally stays short; planning changes belong in `ROADMAP.md` first.
